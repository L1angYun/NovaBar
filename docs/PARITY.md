# 能力与验证边界

本文对应 `0.4.3` 的默认实现，不承诺与其他外观工具的全部功能相同。

## 界面与材质

| 功能 | 范围与限制 |
|---|---|
| 任务栏、开始菜单、通知 / 日历、快捷设置 | 独立外观与启用开关；面板界面默认关闭 |
| 桌面、有窗口、最大化、开始菜单、搜索、任务视图、省电 | 独立状态决策与回退；省电状态默认关闭 |
| Normal、Opaque、Clear | 恢复原始属性、纯色、透明 |
| Blur、Acrylic | 使用系统材质；系统控制模糊行为，面板旧 Blur 值保留兼容行为 |
| LiquidGlass | 从真实窗口与桌面合成来源，提供模糊、折射、色散、色调、噪声和高光 |
| 面板光学 | GPU 准备基础画布；默认由客户端 CPU 计算边带并更新 XAML 位图画刷，另有非默认的共享 GPU 纹理试验 |
| 任务栏光学 | 独立条带路径；符合条件时使用 GPU，其他条件保留真实 CPU 路径 |
| 来源状态 | 首次就绪前透明；等待新帧可沿用有效真实画布，明确不可用或过期时撤下；不自动替换为 Acrylic 或静态壁纸 |
| 打开 / 收起动画 | 有当前几何更新与隐藏来源准备；部分原生独立动画的背景对齐仍有限制，不保证逐帧无拖影 |
| 首次通知宿主 | 新宿主接入和真实背景需要等待，不保证首次可见帧即为玻璃 |
| 圆角 | 跟随目标实际几何与宿主裁剪，无独立圆角开关 |
| 多显示器 | 按各任务栏物理边界采样，支持负坐标；状态决策仍使用引擎当前快照 |
| ShowPeek | 配置字段保留；当前后端不提供开关 |

## 配置与应用

| 功能 | 范围与限制 |
|---|---|
| 规则 | 通用、有窗口、最大化分组；进程名 / 标题 / 类名包含匹配，不区分大小写 |
| 活动 / 非活动外观 | 状态和规则可分别配置 |
| 忽略列表 | 从窗口候选中排除匹配项 |
| JSON、预设 | 导入 / 导出、保存与应用 |
| TTB 导入 | 状态、材质、颜色、规则和忽略列表；保留各窗口状态的独立规则 |
| 自动应用、配置保存 | 可独立控制；失败保留修改并显示原因 |
| 托盘与关闭到托盘 | 打开配置中心、恢复默认、退出配置中心；引擎独立运行 |
| 登录自启 | 当前用户 HKCU Run，无需 SYSTEM 计划任务 |
| 更新 | 自动、GitHub、Gitee 更新源；手动检查与可选启动检查；下载 / 安装分别确认，可取消下载并校验完整性 |
| 安装与卸载 | 当前用户自包含安装；更新保留配置，卸载恢复外观并保留配置 |
| 捕获状态 | 显示未连接、空闲、等待、就绪或暂不可用；过期状态不视为连接有效 |
| 日志 | 提供诊断文件；不承诺完整日志等级过滤或轮转 |

## 自动测试

在仓库根目录运行：

```powershell
.\build\test.ps1
.\build\test.ps1 -Capture
```

常规测试覆盖配置、规则、状态回退、通道隔离、导入 / 导出、恢复流程、帧协议、场景合成、像素处理和调度。`-Capture` 增加真实 WGC 场景和 GPU 检查，会创建受控测试窗口，需要可交互桌面；部分测试依赖可用图形硬件。

定向原生测试包含遮挡、Alpha、颜色键、窗口区域、负坐标、移动、尺寸变化、未知来源等待、纹理代次、后端切换、设备失效与资源分配恢复。GPU 场景与 CPU 参考逐字节比较；基础预处理与条带像素测试使用明确的舍入容差。

这些检查不能替代真实桌面的端到端动画验收。单个像素算法耗时不包含全部上传 / 合成成本；来源序列发布频率、UI 读取频率与 XAML 回调频率均不是显示器帧率。

## 平台与来源边界

- 当前目标为 Windows 11 x64，不承诺 Windows 10、早期 Windows 11 或独立 LegacyComposition 后端支持。
- 受保护内容、系统策略、驱动或来源程序状态可能使捕获不可用；来源暂停也会使真实帧静止。
- 显示切换、隐藏预热和 CPU 回退始终受真实来源完整性、时效及进程所有权检查约束。
- 默认路径保留 BGRA 回读、客户端 CPU 边带与 WriteableBitmap / XAML 上传。显式选择的共享 GPU 纹理试验在受支持设备上避免整幅像素回读，但仍待视觉验收，不是默认发行能力。
