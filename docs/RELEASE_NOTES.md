# NovaBar 0.4.3

- 提供任务栏、开始菜单、通知 / 日历与快捷设置的独立外观、状态规则和 LiquidGlass 参数。
- 在独立捕获进程中共享 WGC / D3D11 来源，执行真实场景合成、基础画布预处理和符合条件的任务栏条带渲染。
- 面板客户端按当前几何计算有限边带光学；保留来源时效、进程所有权、真实 CPU 回退与设备失效恢复检查。
- 共享 GPU 纹理试验面向受支持的面板宿主，允许渲染回调从已映射的元数据读取新帧；安装时不默认启用。
- 关于页提供自动、GitHub、Gitee 三种更新来源、发行说明、可取消下载，以及安装前大小 / SHA-256 校验。启动检查默认关闭。
- 提供当前用户安装程序、自包含运行时、快捷方式与卸载；应用内更新保留配置和更新前的引擎运行 / 还原状态。

安装文件为 `NovaBar-0.4.3-win-x64-Setup.exe`。`update.json` 供应用检查更新，`SHA256SUMS.txt` 提供校验值。原生组件应与 `NovaBar.XamlBridge.v043.dll` 保持版本配套。首次从便携目录迁移时，先退出原目录的配置中心和引擎。

已知限制：首次按需创建通知宿主需要等待接入与真实背景就绪；原生收起动画仍可能带动背景图案，未完成逐帧无拖影视觉验收。默认路径仍需 BGRA 回读、客户端 CPU 边带处理和 XAML 上传。LiquidGlass 不自动回退 Acrylic 或静态壁纸。目标平台为 Windows 11 x64。

完整范围见 [PARITY.md](PARITY.md)，使用与构建方法见 [README](../README.md)。
